# Scaffold and CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Step 0.3 of Phase 0: a working `pipeline/` and `web/` scaffold, the shared schemas that link them, and one command (`just check`) that CI and people both run.

**Architecture:** The catalogue's Pydantic models are the one definition of `catalogue/factors.yaml` and `catalogue/datasets.yaml`. `atlas validate` checks the files against them, and `atlas schemas` exports them to JSON Schema in `shared/schemas/`. The web app generates its TypeScript types from those schemas, and CI fails when a generated file is out of date.

**Tech Stack:** uv, Python 3.13, Pydantic 2, Typer, ruff, pyright, pytest, Hypothesis; Vite, React, TypeScript, MapLibre, Tailwind, Biome, Vitest, Playwright; just, pre-commit, GitHub Actions.

---

## Scope and choices

The spec for this step is already approved: [roadmap.md](../roadmap.md) step 0.3, [architecture.md](../architecture.md), [tech-stack.md](../tech-stack.md) and decisions D03, D13 and D20. This plan adds no new decision. It does make six choices the documents leave open. Each can be reversed in the next round:

1. **Two pull requests, in order.** Part 1 is the tools, `pipeline/`, the schemas, `justfile`, pre-commit, CI and `.claude/settings.json`. Part 2 is `web/`, the type generation, and the web job in CI. Part 2 needs Part 1's schemas, so it branches from `main` once Part 1 is merged.
2. **The catalogue models are the first schema.** The data bundle's manifest schema arrives in Phase 1 with the first bundle. Exporting the catalogue's two models proves the whole chain now, on files that already exist.
3. **Only the dependencies that something imports.** GeoPandas, Shapely, pyogrio, h3, DuckDB and pyarrow wait for the first spike or task that imports them, which also tests their Windows wheels. shadcn/ui waits for the first component that needs it. [tech-stack.md](../tech-stack.md) moves their "From" column accordingly (Task 11 and Task 20).
4. **Playwright is `just e2e`, not part of `just check`.** It downloads a browser. CI runs both.
5. **Python and the factor explorer both validate the catalogue** until the explorer moves into the web app. Both must pass on the real catalogue, and CI runs both.
6. **No Markdown linting in CI yet.** Earlier pull requests ran a link check and markdownlint from the session scratchpad. Putting them in the repo is a separate task, noted in the backlog (Task 11).

Step 0.3 does not depend on the owner's choice on [D21](../decisions.md) (whether Health care joins the MVP): adding a factor is an edit to `catalogue/factors.yaml` that `atlas validate` then checks.

`pipeline/src/atlas/catalogue/models.py`:

```python
"""The factor catalogue's two files, as Pydantic models.

These models are the one definition of `catalogue/factors.yaml` and
`catalogue/datasets.yaml`: `atlas validate` checks the files against them, and
`atlas schemas` exports them to JSON Schema for the web app. The field
reference is in catalogue/README.md. Rules that span several records, such as
unique ids, live in checks.py.
"""

import datetime
import re
from typing import Annotated, Literal, Self

from pydantic import (
    BaseModel,
    ConfigDict,
    Field,
    StrictBool,
    StrictInt,
    StringConstraints,
    model_validator,
)

Id = Annotated[str, StringConstraints(pattern=r"^[a-z0-9]+(-[a-z0-9]+)*$")]
Text = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1)]
Url = Annotated[str, StringConstraints(pattern=r"^https?://\S+$")]
Weight = Annotated[int, Field(ge=0, le=5, strict=True)]
Score = Annotated[float, Field(ge=0, le=1)]

Scale = Literal["within-city", "across-cities"]
Status = Literal["idea", "researched", "spiked", "built"]
PreferenceType = Literal["fixed", "user-direction", "user-range", "user-choice"]
EvidenceType = Literal["direct", "estimate", "indirect", "perception", "ranking"]
Tier = Literal["city", "country", "global"]
Credibility = Literal["high", "medium", "low"]

SCALES: tuple[str, ...] = ("within-city", "across-cities")

# Licences that allow redistribution and commercial use, by SPDX id (D07).
# Only datasets under one of them may go into public builds. A licence that
# SPDX does not list takes a LicenseRef- id: TfL's open data licence is
# version 2.0 of the Open Government Licence with TfL's amendments.
OPEN_LICENCES: tuple[str, ...] = (
    "OGL-UK-1.0",
    "OGL-UK-2.0",
    "OGL-UK-3.0",
    "CC-BY-3.0",
    "CC-BY-4.0",
    "CC-BY-SA-3.0",
    "CC-BY-SA-4.0",
    "CC0-1.0",
    "ODbL-1.0",
    "CDLA-Permissive-1.0",
    "CDLA-Permissive-2.0",
    "Apache-2.0",
    "LicenseRef-TfL-Open-Data",
)


class _Strict(BaseModel):
    """Rejects unknown fields, so a misspelt field name does not pass unseen."""

    model_config = ConfigDict(extra="forbid")


# --- Scoring curves (docs/methodology/scoring.md, section 3) ---


class Ramp(_Strict):
    shape: Literal["ramp"]
    t0: float
    t1: float

    @model_validator(mode="after")
    def _ends_differ(self) -> Self:
        if self.t0 == self.t1:
            raise ValueError("a ramp needs two different numbers, t0 and t1")
        return self


class IdealRange(_Strict):
    shape: Literal["ideal-range"]
    l0: float
    l1: float
    u1: float
    u0: float

    @model_validator(mode="after")
    def _in_order(self) -> Self:
        if not (self.l0 < self.l1 <= self.u1 < self.u0):
            raise ValueError("an ideal-range curve needs numbers with l0 < l1 ≤ u1 < u0")
        return self


class Lookup(_Strict):
    shape: Literal["lookup"]
    scores: dict[str | StrictInt, Score] = Field(min_length=1)


class Percentile(_Strict):
    shape: Literal["percentile"]
    better: Literal["higher", "lower"]


Curve = Annotated[Ramp | IdealRange | Lookup | Percentile, Field(discriminator="shape")]


# --- factors.yaml ---

# The fields research adds to a measured indicator.
INDICATOR_FIELDS = (
    "unit",
    "preference_type",
    "curve",
    "curve_reason",
    "evidence_type",
    "comparable_across_regions",
    "method",
    "datasets",
)
_RESEARCHED = (
    "unit",
    "preference_type",
    "evidence_type",
    "comparable_across_regions",
    "method",
    "datasets",
    "curve_reason",
)
# The fields each research status requires of a measured indicator, beyond a
# name and a default weight.
REQUIRED_BY_STATUS: dict[str, tuple[str, ...]] = {
    "idea": (),
    "researched": _RESEARCHED,
    "spiked": (*_RESEARCHED, "curve"),
    "built": (*_RESEARCHED, "curve"),
}


class Factor(_Strict):
    id: Id
    name: Text
    description: Text | None = None
    default_weight: Weight
    weight_reason: Text | None = None
    scales: list[Scale] | None = Field(default=None, min_length=1)
    status: Status | None = None
    children: list["Factor"] | None = None
    # Measured indicators only.
    unit: Text | None = None
    preference_type: PreferenceType | None = None
    curve: Curve | None = None
    curve_reason: Text | None = None
    evidence_type: EvidenceType | None = None
    comparable_across_regions: StrictBool | None = None
    method: Text | None = None
    datasets: list[Text] | None = Field(default=None, min_length=1)

    @model_validator(mode="after")
    def _fields_fit_the_kind_of_factor(self) -> Self:
        present = [name for name in INDICATOR_FIELDS if getattr(self, name) is not None]
        if self.children is not None:
            if not self.children:
                raise ValueError("children must be a non-empty list")
            if present:
                raise ValueError(
                    "a factor with sub-factors is not a measured indicator, "
                    f"so it cannot have {', '.join(present)}"
                )
            if self.status is not None:
                raise ValueError(
                    "a factor with sub-factors takes its research status from them, "
                    "so it has none of its own"
                )
            return self
        if self.curve is not None:
            if self.curve_reason is None:
                raise ValueError("a curve needs a curve_reason")
            if self.preference_type == "user-range" and self.curve.shape != "ideal-range":
                raise ValueError(
                    "a user-range measured indicator needs an ideal-range curve, "
                    "because its user drags a band"
                )
        status = self.status or "idea"
        missing = [name for name in REQUIRED_BY_STATUS[status] if getattr(self, name) is None]
        if missing:
            raise ValueError(f"at status {status}, it needs {', '.join(missing)}")
        return self


class FactorsFile(_Strict):
    factors: list[Factor] = Field(min_length=1)


# --- datasets.yaml ---


class Dataset(_Strict):
    id: Id
    name: Text
    publisher: Text
    url: Url
    tier: Tier
    area: Text
    resolution: Text
    date: Text | StrictInt
    licence: Text
    licence_checked: datetime.date | None = None
    public_build: StrictBool
    licence_note: Text | None = None
    attribution: Text | None = None
    tells: list[Text] = Field(min_length=1)
    credibility: Credibility | None = None
    credibility_reason: Text | None = None

    @model_validator(mode="after")
    def _public_build_follows_d07(self) -> Self:
        if self.public_build:
            # A dataset under several licences at once joins their ids with
            # AND, as SPDX expressions do, and each of them must be open.
            closed = [
                part for part in re.split(r"\s+AND\s+", self.licence) if part not in OPEN_LICENCES
            ]
            if closed:
                raise ValueError(
                    f"public_build is true, but {' and '.join(closed)} "
                    f"{'is' if len(closed) == 1 else 'are'} not on D07's list of open licences: "
                    f"{', '.join(OPEN_LICENCES)}"
                )
            if self.licence_checked is None:
                raise ValueError(
                    "public_build is true, so it needs licence_checked, "
                    "the date its licence was checked at the source"
                )
            if self.attribution is None:
                raise ValueError("public_build is true, so it needs an attribution")
        elif self.licence_note is None:
            raise ValueError("public_build is false, so it needs a licence_note saying why")
        if self.credibility is not None and self.credibility_reason is None:
            raise ValueError("credibility needs a credibility_reason")
        return self


class DatasetsFile(_Strict):
    datasets: list[Dataset]
```

`pipeline/src/atlas/catalogue/checks.py`:

```python
"""Catalogue rules that span several records.

models.py checks each factor and dataset alone. This module checks what only
shows across them: unique ids, scales inherited down the tree, weight reasons,
and the dataset ids that measured indicators name. Each check returns a list
of problems, each naming the factor or dataset it concerns.
"""

from collections.abc import Sequence

from atlas.catalogue.models import SCALES, DatasetsFile, Factor, FactorsFile

# 3 is the engineering default. A top-level factor always gives its reason (D14),
# and any other default weight must give its reason too.
DEFAULT_WEIGHT = 3


def check_datasets(datasets: DatasetsFile) -> list[str]:
    problems: list[str] = []
    seen: set[str] = set()
    for dataset in datasets.datasets:
        if dataset.id in seen:
            problems.append(f"dataset {dataset.id}: this id is used more than once.")
        seen.add(dataset.id)
    return problems


def check_factors(factors: FactorsFile, datasets: DatasetsFile) -> list[str]:
    known = {dataset.id: dataset for dataset in datasets.datasets}
    problems: list[str] = []
    seen: set[str] = set()

    def walk(node: Factor, parent_scales: Sequence[str] | None) -> None:
        top_level = parent_scales is None
        if node.id in seen:
            problems.append(f"{node.id}: this id is used more than once.")
        seen.add(node.id)

        if top_level and node.weight_reason is None:
            problems.append(f"{node.id}: a top-level factor needs a weight_reason (D14).")
        elif node.default_weight != DEFAULT_WEIGHT and node.weight_reason is None:
            problems.append(
                f"{node.id}: a default_weight other than {DEFAULT_WEIGHT} needs a weight_reason."
            )

        scales: Sequence[str] = parent_scales or SCALES
        if node.scales is None:
            if top_level:
                problems.append(f"{node.id}: a top-level factor must list its scales.")
        elif parent_scales is not None and not set(node.scales) <= set(parent_scales):
            problems.append(f"{node.id}: it lists a scale that its parent does not have.")
        else:
            scales = node.scales

        if node.children is not None:
            for child in node.children:
                walk(child, scales)
            return

        listed = node.datasets or []
        for index, dataset_id in enumerate(listed):
            if dataset_id in listed[:index]:
                problems.append(f"{node.id}: dataset {dataset_id} is listed twice.")
            elif dataset_id not in known:
                problems.append(f"{node.id}: datasets.yaml has no dataset {dataset_id}.")
            elif node.evidence_type == "ranking" and known[dataset_id].credibility is None:
                problems.append(
                    f"{node.id}: evidence type ranking needs a credibility rating "
                    f"on dataset {dataset_id}."
                )

    for factor in factors.factors:
        walk(factor, None)
    return problems
```

```python
"""Reads the catalogue's YAML files and checks them.

`validate_catalogue` is what `atlas validate` runs. It never raises on bad
content: it returns the problems, so that one run lists them all.
"""

from pathlib import Path
from typing import Any

import yaml
from pydantic import BaseModel, ValidationError

from atlas.catalogue.checks import check_datasets, check_factors
from atlas.catalogue.models import DatasetsFile, FactorsFile
from atlas.paths import CATALOGUE_DIR


def describe(error: Any, raw: Any, file_name: str) -> str:
    """One Pydantic error as a sentence that names the factor or dataset it concerns."""
    label = file_name
    node = raw
    for part in error["loc"]:
        try:
            node = node[part]
        except (KeyError, IndexError, TypeError):
            break
        if isinstance(node, dict) and isinstance(node.get("id"), str):
            label = node["id"]
    field = next((part for part in reversed(error["loc"]) if isinstance(part, str)), file_name)
    if error["type"] == "extra_forbidden":
        return f"{label}: unknown field {field}."
    message = error["msg"].removeprefix("Value error, ")
    if error["type"] == "value_error":
        return f"{label}: {message}."
    return f"{label}: {field}: {message}."


def _parse[T: BaseModel](model: type[T], path: Path, problems: list[str]) -> T | None:
    try:
        raw = yaml.safe_load(path.read_text(encoding="utf-8"))
    except OSError as error:
        problems.append(f"{path.name}: cannot be read ({error.strerror}).")
        return None
    except UnicodeDecodeError:
        problems.append(f"{path.name}: is not UTF-8 text.")
        return None
    except yaml.YAMLError as error:
        problems.append(f"{path.name}: is not valid YAML ({error}).")
        return None
    try:
        return model.model_validate(raw)
    except ValidationError as error:
        problems.extend(describe(item, raw, path.name) for item in error.errors())
        return None


def validate_catalogue(directory: Path = CATALOGUE_DIR) -> list[str]:
    """Checks `factors.yaml` and `datasets.yaml` in `directory`. An empty list means they pass."""
    problems: list[str] = []
    datasets = _parse(DatasetsFile, directory / "datasets.yaml", problems)
    factors = _parse(FactorsFile, directory / "factors.yaml", problems)
    if datasets is not None:
        problems.extend(check_datasets(datasets))
    if factors is not None and datasets is not None:
        problems.extend(check_factors(factors, datasets))
    return problems
```

```python
from pathlib import Path
from typing import Annotated

import typer

from atlas.catalogue.load import validate_catalogue

app = typer.Typer(help="Livability Atlas data pipeline.", no_args_is_help=True)

def validate(
    catalogue_dir: Annotated[
        Path, typer.Option(help="The folder holding factors.yaml and datasets.yaml.")
    ] = CATALOGUE_DIR,

    """Check the factor catalogue against its rules."""
```

```python
"""Exports the catalogue models to JSON Schema, the contract with the web app."""

import json
from pathlib import Path

from pydantic import BaseModel

from atlas.catalogue.models import DatasetsFile, FactorsFile

SCHEMAS: dict[str, type[BaseModel]] = {
    "factors.schema.json": FactorsFile,
    "datasets.schema.json": DatasetsFile,
}
COMMENT = "Generated by `just generate` from pipeline/src/atlas/catalogue/models.py. Do not edit."


def write_schemas(directory: Path) -> list[Path]:
    """Writes each schema into `directory`, with Unix line endings so that git sees no change."""
    directory.mkdir(parents=True, exist_ok=True)
    written = []
    for file_name, model in SCHEMAS.items():
        schema = {"$comment": COMMENT, **model.model_json_schema()}
        path = directory / file_name
        text = json.dumps(schema, indent=2, ensure_ascii=False) + "\n"
        path.write_text(text, encoding="utf-8", newline="\n")
        written.append(path)
    return written
```

```tsx
import { Map as MapLibreMap, setWorkerUrl } from "maplibre-gl";
import "maplibre-gl/dist/maplibre-gl.css";
import workerUrl from "maplibre-gl/dist/maplibre-gl-worker.mjs?url";
import { useEffect, useRef } from "react";
import { LONDON_BOUNDS, LONDON_CENTRE } from "./london";

// MapLibre 6 looks for its worker script beside the bundle, where Vite does not
// put it. Importing it with ?url makes Vite emit it, and this points MapLibre there.
setWorkerUrl(workerUrl);

// OpenFreeMap needs no key (docs/tech-stack.md).
const STYLE_URL = "https://tiles.openfreemap.org/styles/liberty";

export function BaseMap() {
  const container = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!container.current) return;
    const map = new MapLibreMap({
      container: container.current,
      style: STYLE_URL,
      center: LONDON_CENTRE,
      zoom: 10,
      maxBounds: [
        [LONDON_BOUNDS[0] - 0.5, LONDON_BOUNDS[1] - 0.3],
        [LONDON_BOUNDS[2] + 0.5, LONDON_BOUNDS[3] + 0.3],
      ],
    });
    return () => map.remove();
  }, []);

  return <div ref={container} data-testid="map" className="h-full w-full" />;
}
```
