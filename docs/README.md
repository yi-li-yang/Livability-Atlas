## Plans and decisions

| Document | What it holds |
| --- | --- |
| [roadmap.md](roadmap.md) | Phases, milestones, spikes and exit criteria |
| [backlog.md](backlog.md) | Features to add by phase, plus not-now and dropped items |
| [decisions.md](decisions.md) | The decision register: every decision with its reasons and history |

Three more folders are created when first needed:

- `specs/` for design specs
- `plans/` for implementation plans
- `spikes/` for one page per feasibility experiment

Specs and plans are named `YYYY-MM-DD-topic.md`.
